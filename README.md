# 💻 Ferramentas de Programação 3

Repositório destinado aos projetos, atividades e exercícios desenvolvidos durante a disciplina.

## 📚 Sobre a disciplina

A disciplina aborda conceitos e ferramentas utilizadas no desenvolvimento de aplicações, com foco na prática de programação, organização de projetos, utilização de frameworks e ferramentas de desenvolvimento.

Este repositório reúne os projetos desenvolvidos ao longo das aulas, servindo também como registro do meu aprendizado durante a disciplina.
